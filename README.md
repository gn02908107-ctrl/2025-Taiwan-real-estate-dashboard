# 🏠 2025年度全國房地產交易分析 Dashboard

用政府公開的實價登錄資料，打造一個可互動篩選的全國房地產交易分析工具，
涵蓋全台 21 縣市、S1~S4 共四季的交易資料，並整合機器學習模型，
提供依歷史交易特徵估算行情的估價工具。

**🔗 [線上 Demo](https://taiwan-real-estate-dashboard-kmu6tjceclycvdbic6s5zn.streamlit.app/)**

## 專案動機

台灣的實價登錄資料是公開的，但原始資料格式複雜、欄位多、且分散在不同檔案中，
一般人很難直接從中看出房價的趨勢或區域差異。這個專案的目標是把這些原始資料
清理、整合成一個資料庫，並做成一個任何人都能上手操作的互動式 dashboard，
讓使用者可以自己篩選縣市、行政區、房屋類型、季度，快速看到想要的房價洞察；
再進一步用迴歸模型學習歷史交易的定價規律，做成一個可以輸入房屋條件、
估算合理行情的工具。

## 主要功能

### 資料視覺化

- **多維度篩選**：季度（S1~S4）、縣市、行政區、房屋類型（中古屋/預售屋）、
  是否含車位，皆可自由組合篩選
- **動態圓餅圖**：呈現交易筆數佔比，選擇單一縣市時自動切換為該縣市的
  行政區佔比，選擇多個縣市時則顯示全國各縣市佔比
- **各行政區平均單價比較**：長條圖呈現，滑鼠移上可看到精確單價（萬元/坪）
- **S1~S4 價格走勢折線圖**：依「行政區 x 房屋類型」分色呈現多條趨勢線，
  圖上直接標示數值，方便比較不同區域、不同季度的漲跌
- **中古屋 vs 預售屋比較**：同一張圖比較兩種房屋類型的單價差異
- **原始資料表**：可自選要顯示的欄位，門牌僅顯示到路名（隱藏巷弄號等細節）、
  日期欄位轉換成可讀格式，並可下載完整版 CSV

### 房屋估價工具

- 用隨機森林迴歸模型（中古屋、預售屋分開訓練），依「行政區、房屋類型、
  車位、建物型態、季度、坪數、格局、樓層、屋齡」等特徵估算單價
- 兩種估價模式：
  - **快速行情查詢**：選擇坪數區間，其餘條件（格局、樓層、屋齡）自動
    帶入該地區/類型/坪數區間的歷史中位數，操作最簡單
  - **個人化估價**：坪數可自行輸入實際數字，貼近特定房屋條件估價

## 資料來源與處理

- 資料來源：內政部不動產交易實價查詢服務網（實價登錄）
- 資料涵蓋：全台 21 縣市，S1~S4 四季，中古屋/預售屋，含車位/不含車位，共 336 張資料表
- 資料清理重點：
  - 篩選出「住家用」且交易標的為「房地(土地+建物)」或「房地(土地+建物)+車位」的資料
  - 將坪數與單價從公制單位換算為台灣慣用的「坪」與「萬元/坪」
  - 處理原始 CSV 中欄位數不一致的髒資料列（`on_bad_lines`）
  - 解決不同縣市存在同名行政區的問題（例如台北市、基隆市皆有「中正區」），
    改用「縣市 + 行政區」的複合欄位避免資料混淆
  - 修正「建築完成年月」等民國年欄位因數字型態推斷而遺失前導零的問題，
    寫入資料庫前強制以字串型態讀取
  - 將中文樓層文字（如「三層」）與部分來源的阿拉伯數字樓層格式統一轉換為數值

## 建模方法與結果

分別針對中古屋、預售屋訓練隨機森林迴歸模型（預售屋因交易當下通常尚未完工，
不採用屋齡特徵），並與線性迴歸做公平對照比較，完整報告見
[regression_report.md](regression_report.md)。

| 房屋類型 | 模型 | 測試 R² | RMSE | MAE |
|---|---|---|---|---|
| 中古屋 | 線性迴歸 | 0.597 | 14.45 | 7.34 |
| 中古屋 | 隨機森林（調參後） | 0.740 | 11.61 | 4.63 |
| 預售屋 | 線性迴歸 | 0.918 | 8.58 | 5.81 |
| 預售屋 | 隨機森林 | 0.980 | 4.20 | 2.12 |

建模過程中的重點決策：

- 中古屋隨機森林原始版本有過擬合現象（訓練/測試 R² 差距 0.184），
  用 `RandomizedSearchCV` 調整 `min_samples_leaf` 後改善至 0.087，
  以少量準確度換取更可靠的泛化能力
- 線性迴歸在測試集上出現少數不合理的負值預測（單價不可能為負），
  隨機森林則因預測機制（葉節點樣本平均）不會產生此問題，但也因此
  無法預測訓練資料範圍以外的極端值
- **模型定位**：這是依歷史交易特徵估算行情的橫斷面迴歸模型，
  不是時間序列預測，無法推算未來（如 2026 年）的房價走勢

## 技術棧

- **Python**：資料清理與整合（pandas、numpy）
- **SQLite**：儲存全國資料，取代原本零散的多個 CSV 檔案
- **Streamlit**：建立互動式網頁 dashboard
- **Altair**：繪製可客製化的圖表（折線圖數值標籤、圖例、hover 提示格式等）
- **scikit-learn**：迴歸建模（線性迴歸、隨機森林）、超參數搜尋
- **joblib**：模型序列化與存檔

## 如何執行

1. 安裝套件：
   ```bash
   pip install -r requirements.txt
   ```
2. 確認 `Database/全國房屋實價登錄資料.db` 路徑正確（`Database` 資料夾需與
   `dashboard.py` 放在同一層）
3. 執行：
   ```bash
   streamlit run dashboard.py
   ```
4. 瀏覽器會自動開啟 `http://localhost:8501`
