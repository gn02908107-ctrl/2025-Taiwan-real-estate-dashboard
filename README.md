# 🏠 全國房地產交易分析 Dashboard

用政府公開的實價登錄資料，打造一個可互動篩選的全國房地產交易分析工具，
涵蓋全台 21 縣市、S1~S4 共四季的交易資料。

## Demo

> LINK：https://taiwan-real-estate-dashboard-kmu6tjceclycvdbic6s5zn.streamlit.app

## 專案動機

台灣的實價登錄資料是公開的，但原始資料格式複雜、欄位多、且分散在不同檔案中，
一般人很難直接從中看出房價的趨勢或區域差異。這個專案的目標是把這些原始資料
清理、整合成一個資料庫，並做成一個任何人都能上手操作的互動式 dashboard，
讓使用者可以自己篩選縣市、行政區、房屋類型、季度，快速看到想要的房價洞察。

## 主要功能

- **多維度篩選**：季度（S1~S4）、縣市、行政區、房屋類型（中古屋/預售屋）、
  是否含車位，皆可自由組合篩選
- **動態圓餅圖**：呈現交易筆數佔比，選擇單一縣市時自動切換為該縣市的
  行政區佔比，選擇多個縣市時則顯示全國各縣市佔比
- **各行政區平均單價比較**：長條圖呈現，滑鼠移上可看到精確單價（萬元/坪）
- **S1~S4 價格走勢折線圖**：依「行政區 x 房屋類型」分色呈現多條趨勢線，
  圖上直接標示數值，方便比較不同區域、不同季度的漲跌
- **中古屋 vs 預售屋比較**：同一張圖比較兩種房屋類型的單價差異
- **原始資料表 + 下載**：篩選後的資料可直接在網頁上瀏覽，門牌僅顯示到
  路名（隱藏巷弄號等細節），並可下載完整版 CSV

## 資料來源與處理

- 資料來源：內政部不動產交易實價查詢服務網（實價登錄）
- 資料涵蓋：全台 21 縣市，S1~S4 四季，中古屋/預售屋，含車位/不含車位，共 332 張資料表
- 資料清理重點：
  - 篩選出「住家用」且交易標的為「房地(土地+建物)」或「房地(土地+建物)+車位」的資料
  - 將坪數與單價從公制單位換算為台灣慣用的「坪」與「萬元/坪」
  - 處理原始 CSV 中欄位數不一致的髒資料列（`on_bad_lines`）
  - 解決不同縣市存在同名行政區的問題（例如台北市、基隆市皆有「中正區」），
    改用「縣市 + 行政區」的複合欄位避免資料混淆

## 技術棧

- **Python**：資料清理與整合（pandas）
- **SQLite**：儲存全國資料，取代原本零散的多個 CSV 檔案
- **Streamlit**：建立互動式網頁 dashboard
- **Altair**：繪製可客製化的圖表（折線圖數值標籤、圖例、hover 提示格式等）

## 如何執行

1. 安裝套件：
   ```bash
   pip install streamlit pandas altair
   ```
2. 確認 `全國房屋實價登錄資料.db` 與 `dashboard.py` 放在同一個資料夾下
3. 執行：
   ```bash
   streamlit run dashboard.py
   ```
4. 瀏覽器會自動開啟 `http://localhost:8501`
